# francistse/homebrew-tap

Homebrew tap for **[Deployboard](https://github.com/francistse/deployboard)** — a local dashboard for your own macOS launchd deployments.

## Install

```bash
brew install --cask francistse/tap/deployboard
```

Upgrade:

```bash
brew upgrade --cask deployboard
```

Uninstall:

```bash
brew uninstall --cask deployboard
```

Then run `deployboard` (binds to `127.0.0.1` only). For a LaunchAgent with `KeepAlive`, use the installer from the main repo:

```bash
curl -fsSL https://raw.githubusercontent.com/francistse/deployboard/main/install-release.sh \
  | bash -s -- --binary "$(brew --prefix)/bin/deployboard"
```

## What's in this repo

| Path | Purpose |
|---|---|
| [`Casks/deployboard.rb`](Casks/deployboard.rb) | Homebrew cask for the published darwin binaries |

That cask is **generated by GoReleaser** on each `v*` tag of [francistse/deployboard](https://github.com/francistse/deployboard). Do not edit it by hand — the next release overwrites it.

## Not this tap

Do **not** install `RoboZephyr/tap/launch-pilot`. That is upstream launch-pilot, not Deployboard.
